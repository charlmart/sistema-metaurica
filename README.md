## Descripcion General
Software desarrollado para la empresa Metaurica S.A. de C.V., enfocado en automatizar y validar procesos criticos de ingenieria y administracion financiera bajo normativas internacionales.

---

## Modulos del Sistema

### 1. Modulo Tecnico: Validacion de Planos de Ingenieria
* Permite ingresar el codigo identificador del plano, la medida real de la pieza y la tolerancia permitida.
* Calcula las desviaciones dimensionales con base en parametros estrictos de control de calidad.
* Valida el tipo de material utilizado (Acero o Aluminio) para emitir un dictamen final de aprobacion o rechazo.

### 2. Modulo Financiero: Gestion de Ventas y Comisiones
* Registra los datos del cliente y el monto total facturado.
* Calcula de forma automatizada la comision correspondiente para el agente de ventas y el rendimiento neto de la empresa.
* Administra el estatus de cobro de las transacciones financieras (Pagado / Pendiente).
